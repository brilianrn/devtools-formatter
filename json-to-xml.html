Tentang Konverter JSON ke XML

JSON to XML mengubah dokumen JSON menjadi XML yang well-formed, lengkap dengan deklarasi, indentasi, dan escaping karakter khusus. Konversi ini sering dibutuhkan ketika API modern berbicara JSON sementara sistem lawas di sisi lain — SOAP, mesin ETL, atau layanan pemerintahan — hanya menerima XML.

Karena JSON tidak mengenal konsep atribut, tool ini memakai konvensi yang sudah umum dipakai: key yang diawali @ menjadi atribut elemen induk, dan key #text menjadi isi teks elemen. Array diterjemahkan menjadi elemen berulang, dengan tiga pilihan penamaan agar hasilnya sesuai skema tujuan Anda.

Nilai null dikeluarkan sebagai elemen kosong bertanda xsi:nil="true" sesuai XML Schema, dan nama key yang tidak sah sebagai nama elemen XML disanitasi otomatis. Setiap hasil konversi langsung diuji ulang memakai DOMParser bawaan browser, sehingga Anda tahu output benar-benar well-formed sebelum dipakai.

Pertanyaan yang sering diajukan

Bagaimana array JSON diterjemahkan ke XML?

XML tidak punya tipe array, jadi setiap elemen array ditulis sebagai elemen berulang. Anda bisa memilih apakah nama elemennya mengulang nama key induk, selalu memakai tag item, atau memakai bentuk tunggal dari nama key induk.

Bagaimana cara membuat atribut XML dari JSON?

Beri awalan @ pada nama key, misalnya "@id": "SO-4471". Key seperti itu akan menjadi atribut pada elemen induknya, bukan elemen anak. Fitur ini bisa dimatikan lewat opsi di atas editor.

Apa yang terjadi pada nilai null?

Nilai null dikeluarkan sebagai elemen kosong dengan atribut xsi:nil sama dengan true, sesuai konvensi XML Schema, dan namespace xsi ditambahkan otomatis pada elemen akar bila diperlukan.

Bagaimana kalau nama key mengandung spasi atau tanda baca?

Nama elemen XML tidak boleh mengandung spasi dan tidak boleh diawali angka. Karakter yang tidak sah diganti dengan garis bawah, dan nama yang diawali angka diberi awalan garis bawah, sehingga output tetap well-formed.

Apakah hasilnya dijamin valid?

Hasilnya dijamin well-formed karena diverifikasi ulang dengan DOMParser browser setelah konversi. Validitas terhadap sebuah XSD tertentu adalah hal berbeda dan bergantung pada skema tujuan Anda.
