Tentang SQL Formatter & Minifier

SQL Formatter menata ulang query yang ditulis dalam satu baris panjang menjadi bentuk berindentasi dengan klausa SELECT, FROM, JOIN, WHERE, GROUP BY, dan ORDER BY yang sejajar, sehingga struktur query langsung terbaca saat review kode maupun saat menelusuri query lambat di log database.

Dua belas dialek didukung, mulai dari Standard SQL, MySQL, MariaDB, PostgreSQL, SQLite, T-SQL, dan PL/SQL, sampai gudang data modern seperti BigQuery, Snowflake, Redshift, Spark SQL, dan Trino. Memilih dialek yang tepat penting karena tiap vendor punya kata kunci dan sintaks literal sendiri.

Tombol Minify memadatkan query menjadi satu baris dan membuang komentar, berguna saat query perlu ditempel ke dalam string konfigurasi. Pemadatan dilakukan dengan pemindai yang menghormati literal string dan identifier berkutip, jadi isi 'teks dengan spasi' tidak ikut dirusak.

Pertanyaan yang sering diajukan

Apakah query saya dikirim ke server?

Tidak. Pustaka sql-formatter dimuat dari CDN lalu berjalan sepenuhnya di browser. Query, nama tabel, dan literal apa pun yang Anda tempel tidak pernah meninggalkan perangkat Anda.

Kenapa saya harus memilih dialek yang tepat?

Setiap vendor punya kata kunci dan aturan kutip sendiri. Misalnya backtick pada MySQL, tanda kurung siku pada T-SQL, dan fungsi window khas BigQuery. Memilih dialek yang sesuai membuat pemformatan mengenali konstruksi tersebut alih-alih menganggapnya sintaks tak dikenal.

Apakah formatter ini mengubah arti query saya?

Tidak. Yang diubah hanya spasi, baris baru, indentasi, dan besar-kecil huruf kata kunci. Nama tabel, nama kolom, dan isi literal string tidak pernah disentuh, sehingga hasil eksekusi query tetap sama persis.

Bisakah memformat beberapa statement sekaligus?

Bisa. Statement yang dipisahkan titik koma akan diformat berurutan, masing-masing dengan indentasi sendiri. Ini berguna untuk file migrasi yang berisi banyak perintah DDL.

Kenapa Minify tidak menghapus semua spasi?

Spasi yang berada di dalam literal string atau di dalam identifier berkutip sengaja dipertahankan, karena menghapusnya akan mengubah data yang dihasilkan query. Yang dibuang hanyalah whitespace struktural dan komentar.
