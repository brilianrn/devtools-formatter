Base64 Encoder & Decoder

Tentang Base64 Encoder & Decoder

Base64 adalah skema pengkodean yang mengubah data biner menjadi 64 karakter ASCII yang aman dilewatkan melalui kanal teks: body email MIME, atribut src data URI, header HTTP, atau field JSON. Setiap tiga byte sumber menjadi empat karakter keluaran, sehingga ukuran data bertambah sekitar 33 persen.

Tool ini menangani teks non-ASCII dengan benar. Input diubah dulu menjadi byte UTF-8 lewat TextEncoder sebelum di-encode, jadi karakter beraksen, aksara non-Latin, dan emoji tetap utuh setelah proses bolak-balik — masalah klasik yang muncul kalau btoa() dipanggil langsung terhadap string.

Varian URL-safe menukar karakter + dan / menjadi - dan _ serta membuang padding, sesuai RFC 4648 §5. Varian inilah yang dipakai pada JSON Web Token dan parameter query. Saat decode, kedua varian dikenali otomatis.

Pertanyaan yang sering diajukan

Apakah Base64 sama dengan enkripsi?

Bukan. Base64 hanyalah pengkodean, bukan pengamanan. Siapa pun bisa membalikkannya tanpa kunci apa pun. Jangan pernah memakai Base64 untuk menyembunyikan password, token, atau data pribadi.

Kenapa hasil encode saya lebih panjang dari teks aslinya?

Karena setiap tiga byte data diwakili oleh empat karakter Base64. Pertambahan ukurannya sekitar 33 persen, ditambah padding dan baris baru bila opsi pemotongan baris diaktifkan.

Bisakah tool ini meng-encode file gambar atau PDF?

Bisa. Klik Upload file dan pilih file apa pun. Isinya dibaca sebagai data biner mentah, lalu di-encode utuh, sehingga cocok untuk membuat data URI gambar atau lampiran email.

Apa itu URL-safe Base64 dan kapan saya membutuhkannya?

Base64 standar memakai karakter + dan / yang punya arti khusus di dalam URL. Varian URL-safe menggantinya dengan - dan _ serta menghapus tanda = di akhir, sehingga string bisa ditempel langsung ke path atau query string tanpa perlu percent-encoding.

Kenapa hasil decode saya tampil sebagai hex dump?

Artinya byte hasil decode bukan teks UTF-8 yang sah, biasanya karena sumbernya memang file biner seperti gambar. Tool menampilkan hex dump agar isinya tetap bisa diperiksa, dan tombol Download akan menyimpan byte aslinya sebagai file.
