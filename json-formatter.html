Tentang JSON Formatter, Validator & Minifier

JSON Formatter merapikan dokumen JSON yang berantakan menjadi struktur berindentasi yang mudah dibaca, memadatkannya kembali menjadi satu baris saat Anda butuh ukuran file sekecil mungkin, dan memberi tahu persis di baris dan kolom mana sebuah dokumen gagal di-parse.

Seluruh proses berjalan di dalam browser Anda memakai parser JSON bawaan JavaScript. Payload yang Anda tempel tidak pernah dikirim ke server mana pun, sehingga aman dipakai untuk response API produksi, konfigurasi berisi kredensial, atau log yang memuat data pelanggan.

Gunakan tombol Format untuk indentasi 2 spasi, 4 spasi, atau tab; Minify untuk membuang seluruh whitespace; dan Validate untuk memeriksa dokumen tanpa mengubah output. Opsi urutkan key membantu ketika Anda ingin membandingkan dua dokumen JSON yang urutan fieldnya berbeda.

Pertanyaan yang sering diajukan

Apakah data JSON saya dikirim ke server?

Tidak. Parsing, format, dan minify seluruhnya dijalankan oleh JavaScript di browser Anda. Tidak ada request jaringan yang membawa isi editor, jadi dokumen berisi data sensitif tetap berada di perangkat Anda.

Kenapa JSON saya dianggap tidak valid padahal terlihat benar?

Penyebab paling umum adalah koma di akhir elemen terakhir (trailing comma), penggunaan tanda kutip tunggal, key tanpa tanda kutip, atau komentar bergaya JavaScript. Spesifikasi JSON tidak mengizinkan keempatnya. Pesan error di bawah editor menyebutkan baris dan kolom persisnya.

Berapa ukuran file maksimal yang bisa diproses?

Batasnya adalah memori tab browser Anda. Dokumen sampai beberapa megabyte umumnya diproses dalam hitungan milidetik. File yang sangat besar bisa membuat editor terasa berat karena syntax highlighting, bukan karena proses formatnya.

Apa bedanya Format dan Minify?

Format menambahkan baris baru dan indentasi agar dokumen mudah dibaca manusia. Minify membuang seluruh spasi dan baris baru sehingga ukuran transfer menjadi sekecil mungkin. Keduanya menghasilkan dokumen JSON yang secara data identik.

Apakah urutan key akan berubah setelah diformat?

Tidak, kecuali Anda mencentang opsi urutkan key. Secara default urutan asli dipertahankan sesuai urutan kemunculan di dokumen sumber.
